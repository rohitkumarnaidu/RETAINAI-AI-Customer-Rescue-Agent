# Data Requirements Specification

## Entities & Relationships

### 1. Account / Customer (`customers`)
- `id` (UUID/String, PK)
- `name` (String)
- `domain` (String)
- `tier` (String: Enterprise, Mid-Market, SMB)
- `mrr` (Float)
- `csm_name` (String)
- `renewal_date` (Date)
- `health_score` (Float, 0-100)
- `risk_level` (String: LOW, MEDIUM, HIGH, CRITICAL)
- `status` (String: ACTIVE, AT_RISK, RESCUED, CHURNED)
- `created_at` (Timestamp)

### 2. Usage Events (`usage_events`)
- `id` (String, PK)
- `customer_id` (FK -> customers.id)
- `timestamp` (Timestamp)
- `dau` (Integer)
- `license_utilization_pct` (Float)
- `core_feature_clicks` (Integer)
- `export_events` (Integer)
- `admin_logins` (Integer)

### 3. Support Tickets (`support_tickets`)
- `id` (String, PK)
- `customer_id` (FK -> customers.id)
- `created_at` (Timestamp)
- `resolved_at` (Nullable Timestamp)
- `severity` (String: LOW, MEDIUM, HIGH, URGENT)
- `category` (String: BUG, FEATURE_REQUEST, BILLING, PERFORMANCE)
- `subject` (String)
- `status` (String: OPEN, IN_PROGRESS, RESOLVED, CLOSED)
- `csat_score` (Nullable Integer 1-5)

### 4. Customer Feedback (`customer_feedbacks`)
- `id` (String, PK)
- `customer_id` (FK -> customers.id)
- `timestamp` (Timestamp)
- `channel` (String: NPS_SURVEY, IN_APP_PROMPT, CSM_CALL_NOTES)
- `score` (Nullable Integer)
- `sentiment` (String: POSITIVE, NEUTRAL, NEGATIVE)
- `feedback_text` (Text)

### 5. Risk Assessments (`risk_assessments`)
- `id` (String, PK)
- `customer_id` (FK -> customers.id)
- `timestamp` (Timestamp)
- `health_score` (Float)
- `risk_level` (String)
- `primary_driver` (String)
- `detected_signals` (JSON string list)

### 6. Investigation Reports (`investigation_reports`)
- `id` (String, PK)
- `risk_assessment_id` (FK -> risk_assessments.id)
- `customer_id` (FK -> customers.id)
- `created_at` (Timestamp)
- `root_cause_summary` (Text)
- `evidence_ids` (JSON string list)
- `confidence` (String: HIGH, MEDIUM, LOW, INSUFFICIENT_EVIDENCE)
- `missing_evidence` (JSON string list)

### 7. Interventions (`interventions`)
- `id` (String, PK)
- `customer_id` (FK -> customers.id)
- `investigation_id` (FK -> investigation_reports.id)
- `action_type` (String: EXECUTIVE_CHECKIN, TRAIN_SESSION, DISCOUNT_OFFER, BUG_PRIORITIZATION)
- `proposed_plan` (Text)
- `csm_status` (String: PENDING, APPROVED, MODIFIED, REJECTED)
- `executed_at` (Nullable Timestamp)

### 8. Intervention Outcomes (`intervention_outcomes`)
- `id` (String, PK)
- `intervention_id` (FK -> interventions.id)
- `customer_id` (FK -> customers.id)
- `evaluated_at` (Timestamp)
- `health_score_before` (Float)
- `health_score_after` (Float)
- `health_delta` (Float)
- `outcome_status` (String: SUCCESS, PARTIAL_SUCCESS, FAILED, UNKNOWN)

### 9. Experience Memory Bank (`experience_memories`)
- `id` (String, PK)
- `customer_segment` (String)
- `risk_pattern` (String)
- `trigger_signals` (JSON string list)
- `recommended_action` (String)
- `success_count` (Integer)
- `failure_count` (Integer)
- `confidence_score` (Float)
- `validated_at` (Timestamp)
